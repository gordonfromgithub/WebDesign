# Visual Appeal
Icons Used:
-Trophy (For records page)
-Omamori (For fanmail page)
-Camera (For gallery)
-Carrot/Horseshoe/Ticket (Miscellaneous icons that can fit anywhere on the site)

Insofar, I’m sticking with my pre-established color palette of white, lime, and pink; due to it being a color combination that simultaneously creates contrast and is easy on the eyes. I don’t have many curved lines or shapes; only rectangles and straight lines that may be visually simple, but keep the viewer’s attention directed where it should be without cluttering the page. In cases where further contrast is necessary, I use a striking red background; typically still accompanied by white text.

I settled on two fonts, Sniglet and Dynapuff, as well as keeping the default font used when not specifying a font family. The first two are quite similar, both carrying an air of inviting and energetic whimsy; though this effect is naturally stronger on the font used for the header, Dynapuff. In contrast, the default font is rather reserved and serious, being suited for important and formal tidbits of information.

# Structure & Organization
My table displays the race history that was already present in my previous assignment in the form of a list. Because all the information displayed follows the same template, a table worked quite naturally for it. Plus, I got to experiment with changing the background color based on placement instead of text color, which I think turned out well enough.

# Design Goals
At first, I attempted to re-format my gallery using flex; as described in the assignment. However, this made it difficult to preserve the uniform grid layout I wanted, and when I checked the example site and saw that it didn’t use flex for its gallery either; I decided that preserving the aesthetic was more important than arbitrarily using extra/different code (although I do understand the attempt to familiarize us with more formats than what we’re comfortable with/the first method that works). The gallery’s main goal is - obviously - to display images; so keeping the images large and organized was ultimately the best call for supporting the goals of the page and site as a whole.

As for the form, I had to make an entirely new page for it, which I think turned out well. Since the submissions aren’t actually functional yet, it’s hard to say that it contributes to a proper “goal” right now; but I eventually hope to be able to display submissions on the website in order to foster a sense of community and appreciation.
