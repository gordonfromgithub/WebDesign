# Component Plan

# Webpage the component will be applied to:
A new page, called "Pedigree"

# Type of component: i.e., featured section, card, side panel, image/content gallery, blog preview, etc.
An image gallery in the shape of a family tree; displaying all of Winning Ticket's ancestors

# Why it's needed: i.e., to draw attention to something, allow the user to do something, address a goal or expectation, etc.
To provide further background on the legacy of the horse, as well as perhaps call attention to the legacy of those who came before him

# Features: i.e., the component requires a heading, paragraph, list, button, and image
Images of all the horses, captions with the horses' names, and lines detailing which horses sired which descendants

# What you'll use to build it: i.e., Flexbox, Grid, or both?
Grid; the ability to space objects differently on every row is perfect for a family tree
